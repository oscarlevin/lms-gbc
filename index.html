Common Column Match Regex Patterns

Patterns match case-insensitively against column headers. Click Insert to place a pattern into the rule you were editing, or Copy to clipboard.

Pattern What it Matches / Example Action
^Homework\s*\d+
Columns starting with "Homework" followed by a number (e.g. Homework 1, Homework 2)
^Quiz\s*\d+
Quizzes starting with "Quiz" and a number (e.g. Quiz 1, Quiz 2)
^(Exam|Midterm|Test)
Any column starting with "Exam", "Midterm", or "Test"
^\d+\.\d+ Preview
Section-numbered previews (e.g. 1.1 Preview, 2.3 Preview)
^\d+\.\d+ Exercises
Section-numbered exercises (e.g. 1.1 Exercises, 3.2 Exercises)
^(\d+\.\d+ (Preview|Exercises))
Matches both section Previews and Exercises combined
^(UD|CD|AD|ID|CC)\s*\d+
Standards/targets starting with specific two-letter codes (e.g. UD 1, CD 2)
Participation
Contains the word "Participation" anywhere in the column name
^Project
Any assignment starting with "Project"
